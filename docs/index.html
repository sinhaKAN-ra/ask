The Real Developer Dilemma

How ask fits into your modern coding workflow alongside heavy AI agents.

🤖

The Main AI Agent

Built for big refactors, multi-file codebases, and architectural discussions. Powerful, but overkill and slow when you just need a flag, regex, or quick sanity check.

Best for: heavy lifting & large tasks
🌐

The Browser Tab

Switching away from your editor to ChatGPT or Claude breaks deep focus. You wait for web UI rendering, open yet another tab, and leave RAM-eating windows idling in the background.

Friction: breaks focus & flow
The Solution
⚡

ask in Your Terminal

Type a quick question right in your VS Code terminal. It runs in 0.5s, answers clearly with syntax highlighting, and exits. 0 MB memory when idle. No server, no tab.

Spawn ➔ Answer ➔ Exit (0 MB idle)

Self-Assessing Live Web Fallback

It doesn't guess on fresh information — the model itself knows when to search.

1

Direct Answer First

For timeless questions ("how does TCP handshake work?"), it answers immediately from LLM weights in under a second.

2

Machine-Readable Check

The model appends a hidden self-assessment: NEEDS_WEB: yes | no. If it flags that information may be past its training or time-sensitive, search triggers.

3

Live Grounded Re-Ask

Fetches real-time search results (keyless DuckDuckGo, Tavily, Serper, or Brave) and grounds the final answer with clickable citation links [1].

4

Zero Idle Overhead

Search happens only during that single command. Nothing stays running in the background after the answer is printed.

Built for Modern Terminals

Everything you need from an everyday command-line companion.

🎨

Terminal-Width Responsive

Automatically measures your terminal columns. Wraps markdown smoothly, creates clean code block borders, and formats tables so lines never wrap awkwardly.

🎛️

Controlled Formats

Switch between --format rich (ANSI styled), --format plain (no escape codes), or --format md (raw Markdown for piping to files).

🪟

Cross-Platform Native

Auto-enables VT100/ANSI processing and UTF-8 console output on Windows 10+ (PowerShell and cmd.exe). Works identically across macOS, Linux, and WSL.

✂️

Line-Slice Context

Pass only the lines you care about: ask -f server.py:40-85 "why is this slow?". Prevent context-window bloat effortlessly.

📥

Piped Stdin Context

Pipe logs, git diffs, or commands: cat err.log | ask "summarize root cause" or git diff | ask "write commit msg".

🔌

Any OpenAI-Compatible Provider

Defaults to lightning-fast free Groq. Easily switch to Gemini, OpenRouter, Cerebras, or fully local private Ollama in ~/.ask-cli/config.json.

Install in Seconds

Pure Python standard library with zero runtime dependencies.

$ pipx install aolbeam-ask

Installs an isolated binary executable ask directly onto your PATH.

$ curl -fsSL https://raw.githubusercontent.com/sinhaKAN-ra/ask/main/install.sh | bash

Downloads the single-file script to ~/.ask-cli and symlinks to ~/.local/bin/ask.

PS> irm https://raw.githubusercontent.com/sinhaKAN-ra/ask/main/install.ps1 | iex

Installs for Windows PowerShell & Command Prompt, adding wrappers to User PATH.

$ brew install sinhaKAN-ra/tap/ask

Managed Homebrew tap installation for macOS & Linux.

$ uvx aolbeam-ask "your question"
