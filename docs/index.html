Why it's different

Most terminal AI tools pick one extreme. ask fills the empty middle.

🐢

Never search

Fast, but confidently wrong on anything after the model's training cutoff.

🔁

Always search

Accurate on fresh facts, but slow and heavy on every single query.

🎯

ask: search when stale

The model self-assesses its own answer and only searches when it admits it might be out of date.

How it works

A simple, reliable mechanism — model self-reporting, not fragile phrase-matching.

01

Answer

The model answers your question normally.

02

Self-assess

It appends a hidden line: NEEDS_WEB: yes/no + a reason.

03

Decide

ask reads that line, strips it from view, and searches only if flagged.

04

Ground & cite

Re-asks grounded in results, prints the answer with numbered sources.

Features

Everything you'd want from a terminal companion — and nothing resident when idle.

🪶

Zero idle memory

No daemon, no server. Each call spawns, runs ~1–2s, prints, and exits.

🔌

Any OpenAI-compatible API

Groq, Gemini, OpenRouter, Cerebras, or a fully local Ollama.

📄

File & line context

ask -f big.py:50-120 "..." — send only the lines you need.

📥

Stdin piping

cat error.log | ask "what broke?"

🔎

Pluggable search

Keyless DuckDuckGo by default; Tavily, Serper, or Brave with a key.

💬

Conversation memory

Readable sessions you can list, resume, and rename.

Install

The package is aolbeam-ask; the command is ask.

pipx (recommended)

pipx install aolbeam-ask

pip

pip install aolbeam-ask

Homebrew

brew install sinhaKAN-ra/tap/ask

One-line script

curl -fsSL https://raw.githubusercontent.com/sinhaKAN-ra/ask/main/install.sh | bash

Then get a free key at console.groq.com/keys, export GROQ_API_KEY="gsk_...", and run ask "hello". Full docs in the README.
